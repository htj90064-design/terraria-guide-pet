# 制作过程

目标是保留 Terraria 游戏内向导的低分辨率像素感，而不是重新设计成细腻的大头插画。

1. 以官方 26 × 46 原图和用户提供的游戏截图确认比例、发型和配色。将官方图按最近邻整数倍放大，作为清晰的造型约束。
2. 用 `gpt-image-2` 生成基础形象，经过与原图的并排比对后，作为每组动作共同的身份参考。
3. 分别生成常规动作条。右向奔跑确认可安全翻转后，按帧水平翻转为左向奔跑，保持原来的时间顺序。
4. 提取并检查全部动作。跳跃采用共享视口保留垂直变化；其他动作统一人物高度和足底位置。
5. 先确定上、右、下、左四个关键视线姿态，再按顺时针生成两组连续的八帧视线条。通过完整行重绘修正不清楚的左向姿态。
6. 采用最近邻缩放组装 v2 图集，清理透明边缘，校验单元格与透明像素。修复静止视线帧被重新居中导致的高度偏移。
7. 检查导出的 GIF 帧、帧时长、十六个视线方向与循环衔接，最后执行方向盲测。

原始生成提示保存在 [generation-prompts.md](generation-prompts.md)。其中提到的参考图和布局图属于制作时的输入文件；出于最小化发布内容的考虑，本仓库只列出参考来源，未打包全部输入图、脚本或失败尝试。因此提示集是制作记录，不是可一键复现的构建项目。

这些提示通过已授权的 ImageGen CLI 路径提交。重新生成可能产生不同结果；下载、安装本仓库成品不需要重新生成，也不需要 API 密钥。
