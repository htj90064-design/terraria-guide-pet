# 图集格式

| 项目 | 值 |
| --- | --- |
| 宠物 ID | `terraria-guide` |
| 显示名称 | 泰拉瑞亚向导 |
| `spriteVersionNumber` | `2` |
| 图像 | 透明、无损 WebP |
| 图集尺寸 | 1536 × 2288 px |
| 布局 | 8 列 × 11 行 |
| 单元格 | 192 × 208 px |

行、列均从 0 开始编号。每行中的帧按从左到右排列，未使用格透明。

| 行 | 状态 | 使用列 |
| ---: | --- | --- |
| 0 | `idle` | 0–5；第 6 列为静止视线帧 |
| 1 | `running-right` | 0–7 |
| 2 | `running-left` | 0–7 |
| 3 | `waving` | 0–3 |
| 4 | `jumping` | 0–4 |
| 5 | `failed` | 0–7 |
| 6 | `waiting` | 0–5 |
| 7 | `running`：工作、思考 | 0–5 |
| 8 | `review` | 0–5 |
| 9 | 视线 000° 至 157.5° | 0–7 |
| 10 | 视线 180° 至 337.5° | 0–7 |

视线从向上 000° 开始，每次顺时针递增 22.5°：090° 向屏幕右侧，180° 向下，270° 向屏幕左侧。000° 不是静止正视帧。

安装时应保留 `pet.json` 与 `spritesheet.webp` 的相对位置。不要把 GIF 预览作为安装图集，也不要改变图集尺寸或删除 `spriteVersionNumber`。

常规站立帧高约 155 px，足底位于单元格 y=201。跳跃通过不同帧的垂直位置表达高度，视线动作保持与站立一致的落脚位置。
