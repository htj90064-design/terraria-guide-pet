# 验证记录

本仓库保留的是已经完成制作的图集及最终检查结果。整理发布文件时，没有重新绘制宠物。

## 已完成

- WebP 可解码为 RGBA，尺寸为 1536 × 2288。
- 8 × 11 布局有效：已使用格有内容，未使用格透明。
- 图集校验报告无错误、无警告；透明像素残余 RGB 为零。
- 最终边缘处理保留 alpha，剩余色键边缘像素为零。
- 九组常规动作与全部 GIF 帧、帧时长完成检查。
- 16 个视线方向有分别记录的水平、垂直方向证据。
- 三名独立审查者的多数票盲测确认四个主要方向；所有水平轴分类通过。
- 静止帧与视线帧落脚位置已统一，原有约 20 px 的切换上移已修复。

## 已记录的细微差异

- 067.5°、112.5° 和 157.5° 的上下视线线索较弱，独立盲测中存在不确定性；在有顺序的完整视线动画中接受为细微差异。
- 部分相邻斜向姿态相似，角度变化并不完全等速。
- 157.5° → 180°、337.5° → 000° 的姿态宽度变化更明显；逐帧检查接受为轻微衔接变化。
- 待机、受挫和查看动作幅度较小。

## 验证边界

已检查图像文件、顺序展开的 GIF 帧和帧时长；没有录制或实测 Codex 客户端内播放。AI 生成后的颜色也不是官方原图的逐像素复制。
